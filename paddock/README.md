# PADDOCK WARDROBE

**Paddock** es un asistente de vestuario inteligente con estética motorsport.  
Genera outfits estratégicos según el clima, la ocasión y tu propio armario,  
con sugerencias de estilo y fragancias impulsadas por IA gratuita.
---

##  Características

-  **Generación de outfits** – Combina tus prendas automáticamente según el clima real, la ocasión y reglas de estilo.
-  **Clima en tiempo real** – Obtiene temperatura y humedad de Montevideo (coordenadas configurables).
-  **Detección automática de atributos** – Al añadir ropa, infiere categoría, formalidad y calidez desde el nombre.
-  **Consejo de IA gratuito** – Tip de estilo generado por modelos gratuitos de OpenRouter (sin clave ni registro).
-  **Fragancias inteligentes** – Añadí perfumes escribiendo solo el nombre; la IA completa la información.
-  **Multilenguaje** – Inglés y español, cambio en un clic.
-  **100 % local** – Tus datos se guardan en `localStorage`, nada se envía a servidores externos (salvo el prompt de IA).

---

##  Cómo empezar

1. Cloná o descargá el repositorio.
2. Abrí `paddock.html` en tu navegador.
3. ¡Listo! La IA funciona **sin configuración adicional**.

---

## Configuración (opcional)

Editá el objeto `CONFIG` al inicio de `app.js`:

```javascript
const CONFIG = {
  ANTHROPIC_API_KEY: '',        // clave de Anthropic (opcional)
  WEATHER_LAT: -34.9011,        // latitud para el clima
  WEATHER_LNG: -56.1645,        // longitud para el clima
  OPENROUTER_MODEL: 'google/gemma-3-27b-it:free',  // modelo gratuito
};

# PADDOCK WARDROBE

**Paddock** is an intelligent wardrobe assistant with a motorsport aesthetic.  
It generates strategic outfits based on real weather, occasion and your own closet,  
with AI-powered style tips and fragrance suggestions – all for free.


---

##  Features

-  **Outfit generation** – Automatically combines your clothes using real weather, occasion, and style rules.
-  **Live weather** – Fetches temperature and humidity for Montevideo (coordinates configurable).
-  **Auto-detected attributes** – When adding clothes, it infers category, formality and warmth from the name.
-  **Free AI style tip** – A punchy style suggestion generated by free OpenRouter models (no key or sign-up needed).
-  **Smart fragrances** – Add perfumes by typing just the name; AI fills in the details.
-  **Multilingual** – English and Spanish, switch with one click.
-  **100% local** – Your data stays in `localStorage`, nothing is sent to external servers except the AI prompt.

---

## Getting started

1. Clone or download the repository.
2. Open `paddock.html` in your browser.
3. That's it – the AI works **with zero configuration**.

---

## Configuration (optional)

Edit the `CONFIG` object at the top of `app.js`:

```javascript
const CONFIG = {
  ANTHROPIC_API_KEY: '',        // Anthropic key (optional)
  WEATHER_LAT: -34.9011,        // latitude for weather

  OPENROUTER_MODEL: 'google/gemma-3-27b-it:free',  // free model
